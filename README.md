# GoMeter

Flutter-приложение для отслеживания лимитов подписки OpenCode Go.

## Скрипты

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Структура

- `lib/core/` — тема, настройки, роутинг, adaptive shell.
- `lib/features/` — экраны по фичам (usage, notifications, settings, key, about, onboarding).

Дизайн-основа лежит в `docs/gometer-mockup-md3/`.
